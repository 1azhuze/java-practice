# Project

Java 练习模块，作为 IntelliJ IDEA 工程 `untitled` 的一个子模块使用。

## 结构

```
Project/
├── README.md
├── .gitignore
└── src/
    └── Main.java
```

## 运行

用 IntelliJ IDEA 打开所在工程（`untitled`），在 `src/Main.java` 里点击 `main` 方法旁的运行按钮即可。

## 说明

- `Project.iml`、`.idea/`、`out/` 属于 IDE / 编译产物，已在 `.gitignore` 中排除。
- 本模块独立成一个 Git 仓库，与上级工程 `untitled` 的版本管理互不影响。
